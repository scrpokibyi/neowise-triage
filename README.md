# Тестовое Neowise. AI-помощник для входящих заявок

Менеджер вводит текст заявки и получает тему и черновик ответа. Он читает результат и сам решает, что отправить клиенту. Если AI не справился, менеджер видит понятное сообщение о ручном разборе, а не пустой или неверный черновик.

## Запуск

Нужен Node.js 20 или новее. Зависимостей и ключей нет.

```sh
npm start          # или: node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через переменную `PORT`.

## Тесты

```sh
npm test           # или: node --test
```

Тесты на встроенном `node:test`, без зависимостей. Сервер поднимается на случайном порту.

Что проверяется:
- некорректный ввод (битый JSON, пустое тело, нет `text`, пустая строка, пробелы, не строка, `null`, массив) → `400 {"status":"invalid_input"}`;
- корректный ответ модели → `200 ready` с темой из списка и непустым черновиком;
- сбои имитатора `[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]` → `200 {"status":"manual_review","topic":null,"draft":null}`;
- таймаут укладывается в ~300 мс, даже если модель игнорирует сигнал отмены;
- причина ручного разбора пишется в лог;
- страница: после успешного ответа сбой показывает сообщение о ручном разборе и стирает предыдущий черновик.

Ручная проверка: метки `[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]` в тексте заявки включают сценарии сбоя.

## Что сделано

**API (`server.mjs`)**
- Вход валидируется до вызова модели: тело — JSON-объект, `text` — непустая строка. Иначе `400 invalid_input`.
- Модель ждём не дольше 300 мс: `AbortController` отменяет вызов, а `Promise.race` гарантирует лимит, даже если модель сигнал игнорирует.
- Ответ модели проверяется в `validateModelOutput`: валидный JSON-объект, тема из `delivery | pricing | other`, черновик — непустая строка после `trim`.
- Любой сбой (таймаут, ошибка, битый JSON, чужая тема, пустой черновик) → `200 manual_review`, а причина пишется в лог одной JSON-строкой (`{"event":"triage_manual_review","reason":"timeout"}`). По логу можно считать долю ручных разборов и видеть, что именно ломается.
- Имитатор `mock-ai.mjs` не менялся.

**Страница (`index.html`, `ui.mjs`)**
- При успехе показываются тема (по-русски) и черновик в редактируемом поле: менеджер может поправить текст перед отправкой.
- При `manual_review`, ошибке сервера или сети — сообщение «AI не смог разобрать заявку…», черновик и тема стираются.
- Прошлый черновик стирается сразу при новом запросе, кнопка блокируется на время запроса, ответ на устаревший запрос игнорируется.
- Пустой ввод ловится ещё на странице, сервер всё равно проверяет его сам.
- Логика отображения вынесена в `ui.mjs` без привязки к DOM, поэтому покрыта тем же `node --test`.
